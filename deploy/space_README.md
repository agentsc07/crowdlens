# CrowdLens (hosted demo)

Upload a clip (up to ~15 s) or open one of three pre-indexed MOT17 samples, then ask things like "wearing a red top".
Counts attributes only, never identities. Free-CPU demo: sample questions are cached and instant; new questions on
uploads are slower and only verify the top-8 search shortlist. Source, results and full version:
see the GitHub repository linked from the project README.

Sample footage: MOT17 (Milan et al., 2016), CC BY-NC-SA 3.0, non-commercial use only.
